# BookScan V3 · 四角裁边与全书查找

## 更新现有网站
1. 先在 iPad 导出 PDF 和原图备份。不要清除浏览器网站数据。
2. Windows 解压本 ZIP，将内部全部 10 个文件上传至现有 GitHub 仓库的 main 根目录，替换旧同名文件，并添加 crop.js。点击 Commit changes。
3. GitHub Pages 部署完成后，在原有网址打开，刷新或关闭重开；确认页眉显示 v3 四角裁边。如果仍显示旧版，等待部署完成再重新加载（不要通过清除网站数据解决，以免丢失书页）。
4. 如果尚未部署：Settings → Pages → Deploy from a branch → main / (root) → Save。

## 扫描与裁边
- 将 iPad 固定在书上方，书下铺深色无反光桌垫；确保整个书本的四边都在画面中，周围留出空隙。
- 默认“自动识别书本四边”：绿色边框是估计的书本轮廓，黄色线是书脊分割位置。摄像头预览约每 0.7 秒更新边缘估计，拍摄后从原始照片重新检测。算法基于亮度对比、连通区域与角点估计，低对比度或复杂背景可能失败或误判。
- 最稳妥的方式是“手动校准四角”：开启相机后点击按钮，拖动绿色四角到书本边缘，调整黄色分割线，点击保存。固定机位的后续照片会使用这一组坐标。若书的位置、厚度、相机角度改变，应重新校准。
- 每张拍摄原图按四角做平面透视矫正，再按书脊位置分割左右两页。不是厚书曲面展开。
- 检测失败时保留原图，使用备用比例裁边生成临时页面，并在扫描结果标注“待裁边检查”。请逐组检查，也要检查自动检测成功的结果，防止切掉文字。
- 旧照片无需重拍：在任意一张页卡点击“修正裁边”，查看原图并拖动四角与书脊位置，保存后仅重处理该组。也可用“重新裁边全部”按当前全局模式批处理所有原图（会覆盖旧的逐组裁边设定）。
- 原始照片不会被裁边操作覆盖。被重新处理的页的 OCR 文本（包括人工校对）将失效并被清除，需要重新识别。

## 全书查找与 PDF
- 点击“识别未处理书页”，选简体/繁体中文与英文或仅英文。首次需要网络下载 Tesseract.js OCR 引擎及语言包；照片在设备浏览器中识别。
- 输入关键词，点击搜索结果查看对应页，支持文字校对。
- “生成并保存 PDF”导出当前裁切后的左右页图片，仍为图片型 PDF，没有可全文搜索的隐藏文字层。
- 保留 V2 的 IndexedDB 名称及记录存储方式，同一浏览器、同一网址的旧扫描记录通常可继续使用；Safari 与主屏幕应用存储可能不同，升级前先备份。

## 测试与限制
JavaScript 语法、合成书页边缘检测、低对比度拒绝及透视映射角点数学测试已通过。当前环境阻止本地网页浏览器访问，未能完成端到端浏览器测试或 iPad 摄像头实测。请先导入一张照片，验证边框、手动裁切、保存和 PDF，再连续扫描。
