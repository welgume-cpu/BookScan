# BookScan V5 · 单页／双页自动识别

本项目面向 iPad Safari 的静态网页图书扫描应用：使用 HTTPS 摄像头、自动翻页稳定判定、自动识别纸张四边、透视矫正、页面级 OCR/全书关键词查找及图片型 PDF 输出。全部书页图像保存在 iPad 本机浏览器的 IndexedDB，不上传 GitHub。

## V5 核心变化

- **自动识别**：每次拍摄先自动裁切纸张外轮廓，再结合纵横比、中央书脊阴影和左右文字区域判断单页或双页。单页输出一页，双页输出两页；无法可靠判断则保存原图并标记「待确认」，不擅自切成两页。
- **模式选择**：扫描区可选择「自动识别（推荐）」「固定单页」「固定双页」。固定模式仅影响后续拍摄；在扫描结果中可对单次拍摄点击「改单页」「改双页」，无需重新拍摄。
- **统一页面模型**：从 `left/right` 强制双页升级为 `pages:[{id,side,image,ocrText}]`。实际页数用于缩略图、搜索结果、OCR 和 PDF。
- **旧数据迁移**：沿用 V4 的 `bookscan_v1` / `spreads` IndexedDB，不清空数据。读取旧 V4 `left/right` 时自动构造两个页面并保留原图、旧 OCR 文本及旧字段。此前错误分成双页的封面，可点击「改单页」重新按原图处理。
- **裁边改进**：原有自动亮度边界识别保持不变；额外尝试与背景颜色对比的检测，改善深色、彩色封面。仍要求纸张完整入镜，背景尽量无反光。
- **PDF**：按照实际页面数生成图片 PDF；OCR 用于网站内部搜索，目前 PDF 不含可搜索文字层。

## GitHub Pages 更新

1. 先在 iPad 内导出已有 PDF，尤其要备份跨页/单页原图。**不要清除 Safari 网站数据**。
2. 将解压后的根目录文件（包括新增的 `layout.js`）上传至 `welgume-cpu/BookScan` 的 `main` 分支根目录并覆盖旧文件。不要上传整个 ZIP 代替网页文件。首次部署不需要更改 GitHub Pages 设置。
3. 用 iPad Safari 打开 `https://welgume-cpu.github.io/BookScan/`，刷新并重新打开，确认标题为 `v5 单双页智能识别`。
4. 选择「自动识别」，先导入或扫描封面（1页）、普通跨页（2页）、再导入扉页（1页），确认页面计数为4。若程序不确定，会标记待确认，需要点「改单页」或「改双页」。

## 数据安全与使用限制

- 浏览器缓存和 IndexedDB 可能因 iPad 空间压力、系统清理、清除网站数据或 PWA 重新安装等原因丢失；请定期备份原图和 PDF。升级前尤其建议备份。
- 单页或双页判定使用启发式图像特征，输出的 confidence 不是经校准的统计概率。横向封面、无明显书脊的双页、颜色与桌面相近的封面可能标为待确认。
- 厚书的曲面展开、全书实际漏页核验、可搜索 PDF 文字层及 Safari 真机长时间稳定性测试尚未完成。
- 手动改单双页会重新生成该次拍摄的页面，原先该次的 OCR 需要重新识别；其他拍摄的 OCR 保留。
